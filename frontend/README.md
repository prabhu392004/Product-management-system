# Product Management System - React Frontend

This is a modern standalone React (Vite + Tailwind CSS + Lucide Icons) single-page application for the Product Management System.

## Prerequisites
- Node.js (v18+)
- Backend Django server running at `http://127.0.0.1:8000/`

## Setup & Run

1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at:
   `http://localhost:5173/`
